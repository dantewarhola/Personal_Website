Network Security · DNS

Pi-hole DNS Sinkhole & Network Filtering

Deployed Pi-hole on a Linux-based home network to block ad, tracker, and known-malicious traffic at the DNS layer across every connected device. Used the built-in admin portal to monitor query volume, inspect resolution behavior, and manage blocklists from a local IP portal — a practical look at DNS as both a control point and a telemetry source.

  • Linux CLI
  • Pi-hole
  • DNS Filtering
  • Network Monitoring
  • Blocklists
Home lab · May 2025

Applied Cryptography · Privacy

An encrypted messaging application built for privacy. It operates without accounts or server-side logging, and sessions and messages terminate automatically — minimizing the data that exists to be compromised in the first place. An exercise in threat-modeling a communication tool and designing for data minimization.
